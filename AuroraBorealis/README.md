# 🌌 Aurora Borealis

Shimmering curtains of northern lights dance across the Valheim night sky. Fades in at dusk, out at dawn, and is hidden by rain and snow.

## ⭐ Features:

* Layered, rippling curtains of light with moving rays and a sharp glowing lower edge
* Five colour schemes: Classic green, Violet, Ice, Crimson and Rainbow
* Fades in at dusk and out at dawn (or show it all day)
* Hidden while it rains or snows, and when you are indoors
* Choose where it hangs in the sky, how wide it stretches, how tall and how fast it moves
* Client side only: no need for the server or other players to have it

<br>

## 🎚️ Configuration:

Settings are in `BepInEx/config/MagicMike.AuroraBorealis.cfg` (or edit them in r2modman/Gale/<a href="https://thunderstore.io/c/valheim/p/Azumatt/Official_BepInEx_ConfigurationManager/">Configuration Manager</a>).

| Section | Setting | Default |
|---|---|---|
| General Settings | Enable Plugin | On |
| Aurora | Always Visible | Off |
| Aurora | Brightness (0-200%) | 100 |
| Aurora | Colours | Classic |
| Aurora | Hide In Bad Weather | On |
| Shape | Curtains (1-8) | 4 |
| Shape | Direction (compass bearing, 0 is north) | 0 |
| Shape | Arc Width (degrees, 360 wraps around you) | 140 |
| Shape | Height (%) | 100 |
| Shape | Speed | 1 |

<br>

## 💻 Installation:

### Automatic Install

Plugin is created to be installed with r2modman or Gale.
For Nexus downloads you will need to install manually.

### Manual Install

  * Un-zip and drag the `AuroraBorealis` folder in your `BepInEx/plugins/` folder.
